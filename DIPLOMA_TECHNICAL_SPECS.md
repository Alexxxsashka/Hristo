# Технічні характеристики: Платформа електронної комерції Hristo Airsoft

## 1. Огляд системи
Платформа **Hristo** — це високопродуктивне рішення для електронної комерції промислового рівня, розроблене спеціально для індустрії страйкболу (airsoft). Вона інтегрує передову 3D-візуалізацію, бізнес-аналітику в реальному часі та надійну підсистему планування ресурсів підприємства (ERP). Архітектура розрахована на екстремальну масштабованість та розгортання без простоїв з використанням сучасного серверного стеку.

## 2. Основні архітектурні компоненти
### 2.1. Архітектура фронтенду
- **Фреймворк**: React 18.x з Vite для високошвидкісного HMR (Hot Module Replacement) та оптимізованої збірки.
- **Управління станом**: Zustand для легкого та високопродуктивного управління глобальним станом (автентифікація, кошик, налаштування).
- **Стилізація**: Vanilla CSS з утилітами TailwindCSS, що підкреслюють естетику "Tactical Dark" з використанням ефектів матового скла (glassmorphism) та компонентів, оптимізованих для анімації (Framer Motion).
- **3D-движок**: Three.js та React Three Fiber (R3F) для рендерингу GLTF/GLB моделей у реальному часі та інтерактивної конфігурації.

### 2.2. Бекенд та база даних
- **Середовище виконання**: Serverless-функції Node.js (Vercel).
- **База даних**: PostgreSQL (Neon) з оптимізованим індексуванням для повнотекстового пошуку та складних реляційних запитів.
- **Рівень персистентності**: Кастомна абстракція сервісу бази даних для безшовної взаємодії між фронтендом та API.
- **Зберігання активів**: Vercel Blob Store (політика "лише онлайн") для динамічних зображень, 3D-моделей та документів, що виключає залежність від локальної файлової системи.

### 2.3. Повний стек бібліотек та інструментів
- **Фронтенд-ядро**: React 19, React Router Dom 7.
- **3D-візуалізація**: Three.js, @react-three/fiber, @react-three/drei.
- **Управління станом та синхронізація**: Zustand, BroadcastChannel API.
- **Анімації та UI**: Framer Motion, TailwindCSS 4, Lucide React.
- **Аналітика та Звітність**: Recharts, jsPDF, jspdf-autotable.
- **Валідація та Безпека**: Zod, Bcryptjs, Jsonwebtoken, Helmet, Express-rate-limit.
- **Інтеграції**: Stripe SDK, Firebase SDK, Google GenAI (@google/genai).

## 3. Унікальні функціональні системи
### 3.1. Розширений 3D-конфігуратор зброї
Визначною особливістю платформи є інтерактивний 3D-конфігуратор, реалізований за допомогою наступних рішень:
- **Ядро рендерингу**: React Three Fiber (R3F) та Three.js для декларативного управління 3D-сценою через React-компоненти.
- **Оптимізація ресурсів**: Використання `@react-three/drei` для асинхронного завантаження GLB-моделей з підтримкою Draco-компресії та прогресивного відображення.
- **Динамічна кастомізація**: Пряме маніпулювання графом сцени (scene graph) для миттєвої заміни мешів аксесуарів та накладання PBR-матеріалів на основі стану Zustand.
- **Синхронізація логіки**: Zustand-стор координує зв'язок між вибраними 3D-компонентами, ціною та фізичною сумісністю запчастин у реальному часі.

### 3.2. Бізнес-аналітика в реальному часі (BI Analytics)
Адміністративна панель містить власний BI-движок, побудований на:
- **Серверна агрегація**: Прямі SQL-запити до PostgreSQL з використанням віконних функцій та агрегацій (`DATE_TRUNC`, `SUM`) для мінімізації обробки даних на клієнті.
- **Візуалізація даних**: Recharts для побудови адаптивних векторних графіків (SVG), що забезпечують високу чіткість та інтерактивність (tooltips, zooming).
- **Оптимізація запитів**: Використання B-tree індексів для прискорення фільтрації замовлень за датами та статусами.
- **Логіка періодів**: Динамічне перемикання часових вікон (тиждень/місяць/рік) через параметризовані API-роути.

### 3.3. Підсистема ERP та управління складом
Інтегроване управління запасами базується на наступних технологіях:
- **Генерація варіацій**: Кастомний алгоритм обчислення декартового добутку для автоматичного створення SKU на основі комбінацій атрибутів (колір, розмір).
- **Цілісність даних**: Атомарні транзакції PostgreSQL для запобігання "race conditions" при паралельному списанні залишків під час пікових навантажень.
- **Валідація форм**: Zod-схеми, що гарантують строгу відповідність типів даних перед збереженням у реляційну базу.
- **Контроль запасів**: Система тригерів для автоматичного сповіщення адміністратора при досягненні `min_stock_level`.

### 3.4. Адміністративний аудит та простежуваність
Система безпеки та моніторингу реалізована через:
- **Перехоплення подій**: Кастомні hooks у `databaseService`, які автоматично створюють записи в таблиці `audit_logs` для кожної операції `INSERT/UPDATE/DELETE`.
- **Безпечна ідентифікація**: Вилучення `admin_id` з перевірених JWT-токенів для забезпечення підзвітності кожної дії.
- **Живий потік подій**: Реалізація `ActivityFeed` з використанням Framer Motion для плавної візуалізації нових подій без перевантаження сторінки.

### 3.5. Динамічний движок налаштувань сайту
Система конфігурації без використання коду (No-Code) працює завдяки:
- **Глобальна реактивність**: Використання патерну Observer через BroadcastChannel API для миттєвого оновлення теми та контенту на всіх відкритих вкладках.
- **Хмарний медіа-менеджмент**: Пряма інтеграція з Vercel Blob SDK, що дозволяє завантажувати важкі активи (відео, 3D-моделі) безпосередньо з фронтенду з валідацією на сервері.
- **SEO-оркестрація**: Динамічне оновлення DOM-метаданих через `react-helmet-async`, що синхронізується зі станом бази даних у реальному часі.

## 4. Технічні інновації
- **Цілісність активів "Лише онлайн"**: Жорстка політика, що гарантує відсутність локальних копій активів, змушуючи систему покладатися виключно на хмарні версіоновані ресурси.
- **Движок оптимізації зображень**: Автоматичне стиснення у формат WebP та зміна розміру на стороні клієнта перед завантаженням для мінімізації трафіку та витрат на зберігання.
- **Стандартизована фреймворк-система модальних вікон**: Адаптивна система макетів на основі CSS Flex для складних адміністративних інтерфейсів, що забезпечує повну доступність та зручність прокрутки на будь-яких екранах.
- **Багатомовна інтеграція**: Система перекладів, що враховує контекст і підтримує глибоку інтернаціоналізацію категорій, описів товарів та транзакційних листів.

## 5. Безпека та стабільність
- **Автентифікація**: JWT (JSON Web Token) з безпечною поведінкою, аналогічною HTTP-only cookies, у локальному сховищі (Zustand persist).
- **Авторизація**: Управління доступом на основі ролей (RBAC), що впроваджено як на рівні інтерфейсу, так і на рівні API.
- **Цілісність платежів**: Інтеграція зі Stripe для обробки транзакцій відповідно до стандартів PCI.
- **Безпека бази даних**: Пул з'єднань (через Neon/Postgres) та параметризовані запити для запобігання SQL-ін'єкціям та вичерпанню ліміту з'єднань.

## 6. Унікальні програмні рішення (Unique Software Features)
- **Real-Time Asset Lifecycle Manager**: Власний алгоритм контролю за життєвим циклом медіа-файлів. При заміні або видаленні зображення/3D-моделі в адмін-панелі, система автоматично надсилає запит до Vercel Blob для негайного видалення старого файлу, запобігаючи накопиченню цифрового сміття.
- **Cross-Tab State Synchronization**: Використання BroadcastChannel API у поєднанні з Zustand для синхронізації стану кошика та налаштувань між усіма відкритими вкладками браузера без затримок та потреби в оновленні сторінки.
- **Automated Variant Matrix Generator**: Алгоритм для автоматичної генерації матриці варіацій товарів (на основі декартового добутку атрибутів), що дозволяє керувати тисячами комбінацій товарів з мінімальними зусиллями адміністратора.
- **Adaptive 3D Configurator Engine**: Модульна система завантаження та рендерингу моделей, яка підтримує динамічне накладання текстур та аксесуарів у реальному часі з автоматичною корекцією освітлення залежно від вибраних матеріалів.
